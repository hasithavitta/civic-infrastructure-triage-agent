Civic Infrastructure Triage Agent

Multi-agent system for reporting and triaging civic issues in real time.
Uses a shared, rate-limited demo API key.

AI Triage Pipeline

○
Intake Agent
Understands the report, analyzes the image, removes personal information and identifies the issue and location.
○
Duplicate Check
Checks nearby reports to see whether this issue has already been reported.
○
Severity Classifier
Evaluates urgency, potential hazards and nearby vulnerable locations.
○
Dispatch Agent
Selects the appropriate municipal department and prepares a work order.
